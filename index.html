見やすい本棚

蔵書が増えても、ごちゃつかない。形式は、枠の色でひと目。

  • 形式が色でひと目 … EPUBはオレンジ、漫画はブルー、PDFはグリーンの枠で区別
  • 読みかけゲージ … 続きから、すぐに（読了は「読了 N/M巻」表示）
  • ★お気に入り＆閲覧履歴 … ★を付けた本と、最近読んだ本（何ページまで読んだかも）を上部にまとめて表示。ワンタップで続きへ
  • 冊数バッジ … シリーズに何冊あるか、開かなくても
  • 探す・並べる … 検索（タイトル・巻数・パス）、並び替え（タイトル／更新日／巻数）
  • 作品・シリーズ単位 … 巻ものもまとめて
  • 消しても戻せる … 削除はいったんゴミ箱へ。あとから書庫に戻せます（まとめて戻すのもOK）
  • 書庫をタブで切り替え … 複数の書庫を分けて、すっきり整理。※複数書庫は、買い切りの全機能解除で利用できます（無料版は書庫1つまで）

読んで、そのまま聴ける。EPUB朗読

文字の本は、読むだけのものじゃない。このアプリのEPUBビューアは、本文をそのまま読み上げます。家事をしながら、目を休めながら、移動しながら——画面を見ていなくても物語は進みます。

  • バックグラウンド再生朗読開始ボタン横のチェックを入れるだけ。画面を消しても、他のアプリを開いても朗読は続きます。
  • 読み上げ位置を青枠で追従 … いま読んでいる一文がひと目で
  • 声を選べる … 朗読バーの「声」をタップするたびに、読み上げる声を切り替え
  • 読み上げ位置の移動 … 上の朗読バーをドラッグで、読み上げる文節を前後に動かせます
  • 音量ボタンの2役 … 朗読中は音量調整。朗読を止めているときは、音量ボタンでページを前後に送れます
  • ページ送りはタップでも … 縦書きは画面の左右、横書きは画面の上下をタップで前後のページへ
この□にチェックで「バックグラウンド再生」ON。画面を消しても朗読が続きます。
音量ボタンは2役。朗読中は音量調整、止めるとページ送りに使えます。

よくある質問

どんなファイルが読めますか？
漫画はZIP / CBZ・RAR / CBR・7Z・フォルダ、PDF、文字の本はEPUBに対応。WebP・GIF・BMP・AVIFなどの画像形式も表示できます。
NASやクラウドの本も読めますか？
端末がフォルダとして扱えるネットワーク／同期フォルダなら選べます。（専用のクラウド連携は今のところありません）
朗読の声は変えられますか？
はい。朗読バーの「声」表示をタップするたびに、端末の音声を順番に切り替えられます。
無料でどこまで使えますか？
無料版では、書庫は1つ・先頭から30冊まで本文を読めます（30冊を超える本はロックされます）。アプリ内の買い切り（¥980）で、複数の書庫・冊数無制限などの全機能を解除できます。
広告は表示されますか？
いいえ。広告は一切表示しません。バナーもポップアップもなく、読書のじゃまをしません。
